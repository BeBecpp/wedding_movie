## Day before / morning: rehearsal (separate Zoom TEST meeting)

1. Open a **separate test meeting**, not the wedding meeting. Join from a second device (phone) as the "remote guest".
2. Play the loop in a player set to repeat (VLC: *Loop all*; QuickTime: *View → Loop*). Watch the 3:59 → 0:00 seam once.
3. Share it. Use Zoom's video-share option if available (Share → Advanced → *Video*). Otherwise share the player window and tick **"Optimize for video clip"**. Tick **"Share sound"** only if an authorised track is in use.
4. On the phone, check: names readable, no cropped text, smooth motion, acceptable delay, and no echo.
5. Run the opening film once. Confirm it ends on the steady name card, not a black frame.
6. Stop sharing. Confirm the speaker's camera/mic come back and the caption system (SubTalk) starts normally.
7. If one computer does everything (video + Zoom + mic + SubTalk), watch CPU/GPU/RAM during steps 3–6. Use the 720p files if anything stutters.
8. Music, if approved: decide **one** audio route, either the venue mixer or Zoom "Share sound", never both. Set the level by ear in the room (warm, under conversation) and on the remote phone.

## If something fails

- Video won't play: share `WelcomeStill_1920x1080.png` (full screen) and continue.
- Stutter on Zoom: switch to the `_720p_` file.
- Echo or doubled music: mute one of the two routes (mixer **or** Zoom share sound).
- Don't record or redistribute a stream with copyrighted music unless authorised.
