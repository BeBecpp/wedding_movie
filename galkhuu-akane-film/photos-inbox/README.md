# photos-inbox

Drop the ORIGINAL photos here, named after their slot (see `assets/photo-manifest.json`), e.g.

    COUPLE_HERO_01.jpg
    galkhuu_portrait_01.jpeg
    AKANE_PORTRAIT_01 garden.png

then run `npm run photos`. Originals in this folder are git-ignored and never committed.
Processed, metadata-stripped copies are written to `public/assets/photos/`.
